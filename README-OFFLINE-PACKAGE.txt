This archive mirrors the static API for manual/offline GF2Tools use.
Runtime images are the importer's local output (WebP by default). This packaging step does not decode, resize, or re-encode them.

Safe install:
1. Extract to a temporary directory.
2. Verify gfl2tools-package.json SHA-256 values.
3. Check schema/data_version compatibility.
4. Atomically activate the new cache.
5. Keep the previous cache until activation succeeds.
